# EverPort: Everlasting Summer for PortMaster

Runs the Steam release of Everlasting Summer (Ren'Py 7.4.11, Python 2) on PortMaster's shared **Ren'Py 8.3.4** aarch64 runtime, with assets shrunk to the Anbernic RG40XX H's 640x480 screen. The game isn't included; it's free on Steam.

## Layout

| Path | What it is |
|--|--|
| `port/Everlasting Summer.sh` | PortMaster launcher: mounts the runtime, copies the patch in, starts gptokeyb + Ren'Py |
| `port/everlastingsummer/everlastingsummer.gptk` | Button mapping (see `port/README.md`) |
| `port/everlastingsummer/patches/zz_portmaster.rpy` | Ren'Py 8 compatibility + shrunk-asset support + low-RAM settings |
| `port/everlastingsummer/game/` | Game data, generated by the tool below (not in the repository) |
| `port/port.json`, `port/gameinfo.xml`, `port/README.md` | PortMaster metadata |
| `tools/prepare_gamefiles.py` | Builds `game/` from a Steam install |

## Build the game folder

Needs Python 3 with Pillow, and ffmpeg on PATH.

```bash
python tools/prepare_gamefiles.py "E:/SteamLibrary/steamapps/common/Everlasting Summer"
```

It copies the scripts, fonts and translations, leaves out the Windows modding tools (`game/mods`), Steam's Python 2 cache and your saves, then rebuilds `archive.rpa` with every image downscaled 3x (437 MB to 45 MB) and writes `portmaster_shrink.txt`, which the patch uses to draw each image at its original 1920x1080-layout size. It also re-encodes `video/opening.ogv` from 720p to 360p.

## Install on the handheld

1. Make sure PortMaster is installed and has been opened once on the device.
2. Copy `port/Everlasting Summer.sh` and `port/everlastingsummer/` to your ports folder.
3. Launch "Everlasting Summer" from Ports. If the Ren'Py 8.3.4 runtime is missing, PortMaster downloads it.

## What the patch fixes

- `im.Map` ramps built with `chr()` (bytes in Python 2) crashed the ending credits under Python 3.
- The optional colour filters walked Ren'Py's image table with `dict.iteritems()`.
- Ren'Py's `im.Composite`, `im.Crop`, `im.Scale` and the game's own `VerticalCrop` assume whole-number oversample; the shrunk assets use 1/3, so these get rounding versions.
- The game asks for a 1000-step rollback and desktop cache sizes; the port uses Ren'Py's defaults.
- Ren'Py's own gamepad input is off; gptokeyb handles the controls.
